# AstraFlux-HUB (星流控制中心) 浅色极简交互版宣传物料与视频封面库

本项目所有宣传海报与视频封面严格采用 **纯 HTML/CSS/SVG 代码布局** + **无头浏览器 (Headless Chrome) 高清光栅化渲染** 生成，**100% 纯代码渲染，绝对零 AI 生图**。

---

## 💎 本次设计与定位全面重构亮点

1. **全面采用现代浅色极简界面风格（告别暗色 AI 风）**：
   - 彻底摒弃暗黑发光霓虹、赛博激光线条等廉价“AI味”视觉；
   - 统一采用 **高端科技极简白/浅灰 Studio 浅色调**（`#f8fafc` / `#ffffff`），与软件浅色界面自然融合，视觉清爽通透、高级耐看。
2. **纯粹聚焦「驱动交互体验」，剔除硬件参数**：
   - **绝口不提 8K / 8000Hz / 0.001mm 等硬件 PCB 级指标**（那些属于硬件键盘厂商的差价，本驱动不做越俎代庖的虚标宣传）；
   - **全力聚焦软件自身核心价值**：
     - **直观可视**：曲线实时拖拽，按键行程一目了然；
     - **纯净 0 后台**：用完即关，绝不偷跑开机自启和流氓常驻进程；
     - **告别繁琐**：清爽通透逻辑，新手也能秒上手。
3. **彻底摒弃商用版权字体，全量采用开源无衬线字体**：
   - 全面使用 **Google/Adobe 开源商用无衬线字体「思源黑体」（Noto Sans SC）**，粗体字形规整有力、排版高级、零版权风险。
4. **纯净高反差配色，杜绝脏色渐变**：
   - 采用深邃板岩黑（`#0f172a`）、纯正科技蓝（`#2563eb`）、天蓝（`#38bdf8`）与纯白卡片，字迹边缘锐利，高对比度，缩略图一眼清晰。
5. **文案词汇自然优雅，彻底摒弃粗俗宣称**：
   - 彻底删除“好用”等低质词汇，改用 **「最舒服」**、**「纯净自制」**、**「直观可视」**、**「丝滑」**、**「零门槛」**，同时突出 **「玩家自制」**、**「星闪悦动」**、**「磁轴」**、**「驱动」**。
