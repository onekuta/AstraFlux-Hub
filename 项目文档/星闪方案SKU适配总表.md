## 〇、「SKU 编号」口径说明（先读）

1. **星闪悦动官方没有公开的「产品型号 ↔ VID:PID」对照表。** 官方驱动的设备库（`/js/device-*.js`）只有 VID:PID 白名单，**型号名是设备连接后从 HID 描述符运行时读取的**。站上不存在静态 SKU 名录（已实测确认：官方 JS 全量检索无产品名字段）。
2. 因此本表 **SKU 编号采用 `VID:PID`（十六进制）**：能确认的填具体值并注明来源；公开渠道无法确认的明确标注「未公开」。
3. HID 识别要件：`usagePage 0xFFB0` + `usage 0x01`；一台键盘会枚举出 MI_00~03 多个 HID 接口，驱动侧必须按 `vid:pid` 去重。
4. 适配驱动口径：
   - **官方网页驱动（新）**：`www.xsyd.top/v2-app` —— 7 VID / 222 设备白名单，Chrome/Edge 访问；
   - **新双子星驱动**：`v2-dev.xsyd.top` —— 3 VID / 33 设备；连接双子星设备时官方 v2-app 会提示「双子星设备已识别，是否跳转到双子星设备页面」；
   - **旧版本驱动**：官网导航栏保留入口（v1）；
   - **品牌自研驱动**：前行者 EHUB、艾石头 GTurbo（第二代，客户端+网页双端）、七彩虹自研网页驱动、WuqueStudio Polaris Twin OS 等；
   - **星闪悦动 HUB（本项目）**：桌面端，通用档案 + 专属档案（ES68 / AE64-MAX / DV63 / M6 Ultra 预留 / GENERIC_KEYBOARD 兜底）。

## 五、驱动适配要点（给 SKU 适配整理）

1. **识别白名单**：以 §四 官方库为准 + 主 VID `0x1CA6` 兜底放行（覆盖 AE64-MAX / DV63 等未入库在售机型）；不要退回 `SPARKLINK_VIDS.includes()`，避免 Dragonfly `0x391D:0x1A36`、iKF、MCHOSE 等历史授权残留冒出来。
2. **回报率档位**：SDK `RATE_HZ_TO_SDK` 枚举 125Hz~32KHz 共 9 档；**键盘 UI 一律封顶 8K**（现发行版 SDK 键盘回报率枚举只到 `R8KHz`），32K 仅 ES68 32K 方案硬件支持且需 USB3.0 + EnhanceHidUSB 专用驱动。
3. **能力位驱动 UI**：`features.continuousRt` 当前仅 AE64-MAX = true（固件 ≥0.04）；官方开放到其它机型只改一个布尔值。SDK 现版本无该协议字段，UI/下发链路已就绪、待官方开放。
4. **高级按键能力**（全方案通用）：SOCD / DKS / MPT / MT / TGL / END / RS。
5. **匹配优先级**：`DV63` → `ES68` → `AE64` → `M6` → GENERIC（ES68 必须排在 M6 前，否则含 "M6" 型号误判为鼠标）。
6. **多接口去重**：一台键盘枚举 MI_00~03 多个 HID 接口，按 `vid:pid` 归一化（实测 29 条原始 → 2 台）。
7. **双站差异**：v2-app（222）识别到双子星设备时提示跳转 v2-dev（33）专属页 —— 意味着**双子星方案设备可能存在独立的驱动协议分支**，SKU 适配时建议按方案分组验证。
8. **SDK 版本**（npm 最新，2026-08-24）：`@sparklinkplayjoy/hid@1.0.16` / `protocol-keyboard-v2@1.0.23` / `sdk-keyboard-v2@1.0.29`。
