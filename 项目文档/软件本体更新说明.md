## 二、踩坑记录：`app.asar` 被锁

### 现象

- `软件本体/resources/app.asar` **无法删除、无法改名**（`Device or resource busy` / `WinError 32`）。
- 连带 `软件本体/` 与 `软件本体/resources/` 两个目录也无法改名。
- 项目根目录下 7 个旧构建目录（`release*` / `dist-release` / `reference_docs`）同样卡在各自的 `app.asar` 上。

### 已排除的原因

| 尝试 | 结果 |
| :--- | :--- |
| 查运行进程（`Get-Process` / `tasklist`） | 无 `星闪悦动HUB` 进程在跑 |
| `/usr/bin/rm` 绕过沙箱 rm shim | 仍是 EBUSY |
| `cmd /c rd /s /q` | “另一个程序正在使用此文件” |
| 复制成其它文件名后再操作 | **副本完全自由**，证明锁只针对原文件句柄 |
| `handle64.exe` 查句柄占用 | 无管理员权限，看不到别人句柄 |
| `Stop-Service WSearch` | 需要管理员，失败 |
| `Add-Type` 调 Restart Manager | 被安全策略拦截（运行时代译 .NET） |
| `schtasks` 计划任务绕过 | 被程序黑名单拦截 |

### 关键结论（实测）

| 操作 | 结果 |
| :--- | :--- |
| 读取 `app.asar` | ✅ 可以 |
| **写入 `app.asar`（`r+b` / `ab`）** | ✅ **可以** |
| 在同目录新建文件 | ✅ 可以 |
| 改名 `app.asar.unpacked` | ✅ 可以 |
| 改名 / 删除 `app.asar` | ❌ WinError 32 |
| 改名 `resources/`、`软件本体/` | ❌ Permission denied |

→ **锁是「不带 FILE_SHARE_DELETE 的打开句柄」造成的，只挡改名与删除，不挡读写。**

## 三、更新软件本体的正确姿势（原地覆盖）

因为 **可读、可写，但不能改名 / 删除**，采用 **「解包 → 替换 → 重打包 → 原地覆盖」** 流程：

```bash
cd 工程源码

# 0) 构建最新前端
node node_modules/vite/bin/vite.js build

# 1) 解出现有 app.asar（可读）
node node_modules/@electron/asar/bin/asar.js extract \
  "../软件本体/resources/app.asar" .asar-tmp/app_orig

# 2) 用最新产物替换（dist 全量替换；main.js / preload.js 有改动才同步）
/usr/bin/rm -rf .asar-tmp/app_orig/dist && cp -r dist .asar-tmp/app_orig/dist
# cp electron/main.js  .asar-tmp/app_orig/electron/main.js
# cp electron/preload.js .asar-tmp/app_orig/electron/preload.js

# 3) 重新打包（.node 保持 unpacked，与现有 app.asar.unpacked 对齐）
node node_modules/@electron/asar/bin/asar.js pack \
  .asar-tmp/app_orig .asar-tmp/app_new.asar --unpack "*.node"
```

```python
# 4) 原地覆盖（关键：r+b 打开 + truncate，不要用 rm/mv）
import hashlib
src = r'D:\desk\星闪悦动驱动\工程源码\.asar-tmp\app_new.asar'
dst = r'D:\desk\星闪悦动驱动\软件本体\resources\app.asar'
data = open(src, 'rb').read()
f = open(dst, 'r+b')          # ← 只能读写，不能改名/删除
f.seek(0); f.write(data); f.truncate(); f.close()
print('MD5', hashlib.md5(data).hexdigest(),
      hashlib.md5(open(dst, 'rb').read()).hexdigest())
```

```bash
# 5) 清临时目录（务必用绝对路径 rm，绕开沙箱 shim）
/usr/bin/rm -rf 工程源码/.asar-tmp
```

> ⚠️ **中间产物放 `工程源码/.asar-tmp/`，不要放项目根目录。**
> `.asar` 一旦被访问过就会被句柄锁住删不掉，放根目录会留下清理不掉的残留（历史上已踩过一次）。

### 3.1 沙箱注意

- 临时目录建议固定复用同一个名字；若某次打包后无法删除，直接覆盖它即可（写是允许的）。

### 已验证不可行的方案

- ❌ **`resources/app/` 目录覆盖法**：实测 **`app.asar` 优先级高于 `resources/app/`**。
  （曾放置 `resources/app/package.json` + 探针脚本，启动后**完全未被加载**，确认 `app.asar` 永远先命中。）
- ❌ 改名 / 删除 `app.asar`。
- ❌ 停掉某个进程释放锁（未能定位持有者；重启电脑后可解锁）。

> ⚠️ 若某次更新后 `软件本体` 整个目录想整体替换：需先**重启电脑**释放句柄，或用
> `项目文档/cleanup-legacy-folders.bat`（自提权）清理。

## 六、字体资源（第十七轮新增，第十九轮扩充）

软件是**完全离线**的绿色版，因此字体一律随包内置，不引用任何在线 CDN：

| 用途 | 字体 | 授权 | 文件 |
| :--- | :--- | :--- | :--- |
| 正文 / 黑体 | 思源黑体 Noto Sans SC | SIL OFL 1.1 | `NotoSansSC-{latin,chinese-simplified}-{400,500,700}.woff2` |
| **标题（主）** | **庞门正道标题体 PangMenZhengDao** | **作者声明（非 OFL）** | `PangMenZhengDao.woff2`（1,042,116 字节 / 6231 字形 / v3.12） |
| 标题（备） | 得意黑 Smiley Sans | SIL OFL 1.1 | `SmileySans-Oblique.woff2` |
| 数字 / 键码 | JetBrains Mono | SIL OFL 1.1 | `JetBrainsMono-latin-{400,500,700}.woff2` |

- 源文件：`工程源码/src/assets/fonts/`（**不要放 `public/`** —— `vite.config.js` 里 `base: './'`，
  运行时页面 URL 是 `.../app.asar/dist/index.html`，`public/` 的相对路径会解析到不存在的 `.../app.asar/fonts/`）。
- `@font-face` 声明在 `工程源码/src/index.css` 顶部，
  CSS 变量 `--font-sans` / `--font-title` / `--font-display` / `--font-mono` 在 `:root`。
- ⚠️ 改字体栈时 **`tailwind.config.js` 的 `fontFamily` 要同步改**。
- ⚠️ **庞门正道的授权与另外三款不同**：不是 SIL OFL，而是作者庞门正道（阿门）的「作者声明」——
  企业、个人均可免费商用，但**禁止直接把字库作为商品出售、禁止用于商标注册**。
  本软件只把它用于界面内的文案展示，属于授权范围内。改用途前先确认。
- ⚠️ 庞门正道只有 Regular 一个字重，`@font-face` 里声明成 `font-weight: 400 700`，
  让标题上的 `font-bold` 复用同一份字形，避免浏览器合成伪粗把方正字形拉糊。
- 验收：`node tools/dump-font.cjs http://127.0.0.1:9333`
  （应恰好 11 个 FontFace、无任何 Google CDN 来源；并用 canvas `measureText` 实测宽度确认字形命中）。
