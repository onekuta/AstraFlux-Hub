## 迭代详情

### v0.1 — 项目接手
- 通读 `PROJECT_AI_SPEC.md` 开发规范。
- **纠正核心误解**：前手 AI 认为 DV63 就是星闪全部产品线，实际项目定位是**通用外设 HUB**。
- 参考双子星官方站点（`v2-dev.xsyd.top`）与 v2-app 站点学习。

### v0.2 — AE64-MAX 适配
- `deviceProfiles.js` 新增 AE64_MAX 档案 + 官方全量 VID 描述符。
- 未知设备回落 `GENERIC_KEYBOARD`，不再默认 DV63。
- `keyboardService.js` 三级自动匹配（型号关键词→VID:PID→VID→首设备）。

### v0.3 — 连接与写入修复
- 主页隐藏未连接设备（删除假待机卡）。
- 修复大量设置无法写入键盘：读改写合并 + 诚实警告（不谎报成功）。
- 全局 UI 滑块渐变/焦点环/选中态设计。

### v0.4 — 写入协议对齐官方（关键轮）
- 扒官方站构建产物，解码真实写入流程。
- **三大根因修复**：硬件矩阵坐标、GFSParamSave 闪存提交、Promise.all 并发写入。
- RT 开关 = `performance.mode` 1/0。

### v0.5 — 全量设备库 + EWEADN 风格重构
- **连不上根因**：官方 v2-app 有 7 VID/222 设备，双子星只有 3 VID/33。
- 生成 `sparklinkDevices.js` 全量库，7 VID 同步到 main.js。
- 左侧栏重构：设备卡 + 分组导航 + 板载槽 + 校准按钮。

### v0.6 — 灯光键位 + exe 打包
- 修复灯光键位错位（G/H/J 变 =/Backspace）：收硬件坐标 entries。
- exe 打包：NSIS 安装包 + portable，解决沙箱中文路径打包失败（补丁 app-builder-lib）。
- 主页多设备平铺（VID:PID 标注、连接态反色）。

### v0.7 — 去重 + 板载切换 + 校准页
- 性能/设置页剔除重复选项（休眠、回报率重复）。
- 这两页隐藏大面积键盘展示。
- 多板载 Config1~4 真切换。
- 轴体校准页（白键未校准/绿键已校准，实时填充）。

### v0.8 — 双灯结构修正
- 澄清：AE64-MAX 双灯 = **PCB 单键上下两颗灯珠** + **PCB 一圈底灯装饰灯**（非整条独立灯带）。
- `isDoubleLighting()` 探测 + `lamp` 参数（Single/DoubleLighting）。
- 键帽上下二分渐变 + 底灯装饰灯独立渲染。

### v0.9 — 深色 UI 复刻 + 项目整理（当前）
- **UI 复刻**：照抄前行者 EWEADN 深色主题（背景 `#0a0a0a`、品牌蓝 `#0052d9`、粉紫渐变、PingFang SC 字体）。
- 批量转换全部组件浅色 Tailwind token → 深色 token，构建通过。
- **文件夹整理**：旧 release 产物归入 `releases/`，根目录只留软件入口。
- **文档归档**：SKU 清单、SDK 标准、开发日志、迭代记录归入 `docs/`（**现已更名为 `项目文档/`**）。
