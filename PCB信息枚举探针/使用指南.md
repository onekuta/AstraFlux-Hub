## ⚡ 极速使用流程（只需 30 秒，共 3 步）

### 第一步：连接键盘
- 使用 **USB 数据线** 将待测试的客制化键盘 / PCB 直连电脑（建议插在主板后置 USB 口，请勿使用拓展坞或转接头）。
- 若电脑接了多台键盘，本工具支持**自由点击卡片切换**选择要探测的目标设备。

### 第二步：双击运行纯独立单文件 EXE
- 直接双击本目录下的单独程序：  
  👉 **`星闪PCB适配探针.exe`**
- 窗口打开后，在顶部的【步骤 1：选择要采集的键盘】中点击你要测试的键盘卡片；
- 下方的【品牌/厂商名称】和【产品/型号名称】会自动客观填入（若品牌不清楚可留空，也支持手动修改）；
- 点击中间的 **【🔍 开始硬件深度逆向采集 (只读模式)】** 大按钮。

### 第三步：确认数据并在自选文件夹中保存导出
- 工具将通过星闪 0xFFB0 通信协议执行 10 项深度数据逆向探测（约 3 秒）。
- **星闪 0xFFB0 门禁校验**：
  - 若为**支持星闪协议的键盘**：顶部亮起绿色认证徽章 `✅ 星闪 0xFFB0 通信协议握手通过`，下方回显完整的物理按键、固件版本、上下双灯/单灯架构、空格5灯/10灯独立编辑、出厂轴体与霍尔标定基线等关键参数；
  - 若为**非星闪 0xFFB0 设备**：系统将自动触发门禁拦截 `❌ 未通过星闪 0xFFB0 协议握手 (非星闪 HID 接口设备)`，防止错误建库。
- 确认数据无误后，点击 **【📁 选择保存文件夹并导出适配文件 (.json)】**，在弹出的窗口中选择你想保存的位置（自选保存文件夹）。
- 把保存出的 **`.json` 文件** 直接微信/QQ 发送给开发者即可！大功告成！🎉

## 🛡️ 安全与隐私保障
1. **纯只读模式**：本工具只读取设备出厂参数，**绝不会**刷写固件、复位硬件或改变您键盘现有的任何设置。
2. **纯独立单个 EXE**：单文件绿色免安装，随处拷贝运行，无需安装 Node.js、Python 等任何开发环境。
3. **出厂 SN 隐私保护**：默认对硬件出厂 SN 序列号进行脱敏保护（显示为 `[未导出/隐私保护脱敏]`），如需提供可手动勾选。
4. **自主选定保存目录**：不擅自后台落盘，由用户点击系统弹窗自选目标文件夹后再导出，并在资源管理器中自动高亮。
5. **客观真实原则**：严格忠实于硬件真实上报数据，不清楚的品牌与方案绝不强加臆测胡写。

## 📊 采集与导出的关键硬件数据清单

| 硬件维度 | 采集内容与作用 |
| :--- | :--- |
| **0xFFB0 协议握手** | 校验 `0xFFB0:0x01` 专有通信端口与私有协议握手，一票否决非星闪设备 |
| **物理按键矩阵** | 穿透扫描 0~20 行硬件焊盘，获取实际有效按键数、键位物理坐标与 ratio 宽高比 |
| **芯片固件信息** | 主板识别码 (`boardId`)、固件出厂版本 (`appVersion`)、PCB版本 (`pcbVersion`) 与构建时间戳 |
| **灯珠架构拓扑** | 识别常规单灯位 vs 上下双灯位 (`DoubleLighting`，如 AE64-MAX)，统计整板物理总灯珠数 |
| **空格多灯珠规格** | 探测空格键 5 颗 / 10 颗独立物理灯珠布局，确认单灯珠独立 RGB 调光编辑能力 |
| **边缘装饰灯带** | 识别侧边/底面装饰流光灯带 (`Decorate Area`)、灯珠列数与专属灯效 |
| **支持灯光特效** | 官方 19 种硬件预设灯效模式 + L20 自定义涂色模式全量参数 |
| **出厂默认轴体** | 穿透读取默认轴体编号与板载轴体列表，按硬件真实上报呈现（不臆测、不胡写） |
| **霍尔标定基线** | 读取当前键盘各行按键的霍尔传感器出厂标定 ADC 基准值与行程采样数据 |
| **回报率性能** | 硬件上报的全部支持回报率档位（1K/2K/4K/8K/32K）与硬封顶上限 |

## ❓ 常见问题排查

**Q1：为什么提示“未通过星闪 0xFFB0 协议握手”？**  
A：本探针专用于为星闪键盘驱动进行 0xFFB0 通信协议的硬件数据采集。如果键盘主控芯片不是星闪方案（或者未暴露 0xFFB0 驱动通信接口），驱动端即使入库也无法进行磁轴行程与灯光调控，因此探针会坚决拦截，避免污染适配数据库。

**Q2：接了两台键盘，怎样准确选择？**  
A：软件界面上方会自动列出所有已连接的键盘外设，并标注 `⚡ 星闪 0xFFB0 协议` 与 `0xVID:0xPID`，直接点击对应卡片即可实时切换。

**Q3：产品名称或品牌显示不是我想要的，能改吗？**  
A：可以！选中设备后，直接在【品牌/厂商名称】和【产品/型号名称】输入框中修改为您想要的名字，若不清楚品牌也可以直接留空，导出的文件名和档案内容会完全跟随您的设置生成。
